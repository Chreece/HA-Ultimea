# Security policy

## Supported releases

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose Home Assistant data, Bluetooth identifiers, credentials, or enable unintended device control.

Use GitHub's private security advisory feature for the repository if available. If private reporting is unavailable, contact the maintainer privately before publishing details.

Include the affected integration version, Home Assistant version, impact, reproduction steps, and any proposed mitigation.
