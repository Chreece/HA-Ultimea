# ULTIMEA 2026.10.01.4

### Added

- Dedicated Assist Satellite source routing, independent from voice-assistant volume ducking.
- Configurable Assistant input: No change, eARC, HDMI, Optical, AUX, Bluetooth, or USB.
- Active mapped assistants take source priority and normal media/fallback routing resumes when they return to idle.

### Changed

- Single-bar setups do not require assistant area assignment; multiple-bar setups still use areas.
- Assistant source routing reuses existing ARC/eARC adaptation and per-input default sound-mode behavior.
