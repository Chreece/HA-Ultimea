# ULTIMEA for Home Assistant

Local Bluetooth control for **ULTIMEA Poseidon D80 Boom (U2623)** soundbars.

This integration does **not** contain a hard-coded soundbar address. Home Assistant discovers ULTIMEA advertisements, then connects to the candidate and asks the soundbar itself for its model name before setup. Any Poseidon D80 Boom exposing the verified D80 BLE protocol can therefore be configured independently.

## Current support

- Automatic Bluetooth discovery
- Home Assistant host Bluetooth and connectable Bluetooth proxies
- Device-side model verification (`Poseidon D80 Boom`)
- Device serial and firmware query
- Full initial state query on setup/reconnect (no all-unknown startup)
- Media player entity:
  - Power on/off
  - Absolute volume and volume +/-
  - Mute
  - Sources: eARC, HDMI, Optical, AUX, Bluetooth, USB
  - Sound modes: Movie, Music, Voice, Sport, Night, Game
- Configuration selects:
  - Display brightness: Dim, Low, Medium, Normal, High
  - Screen timeout: Never, 5 s, 30 s, 60 s
  - Prompt sound: None, Low, Medium, High
  - Auto standby: Never, 15/30/60 min, 4/8/12/24/48 h
- Push handling of D80 notifications while connected
- Command acknowledgement validation with state-query fallback when an ACK is missed
- Persistent or on-demand BLE connection mode
- English, German and Greek translations
- Diagnostics

## Not yet decoded

Bass, treble, surround level, X-Upmix and custom EQ are intentionally not guessed. They should be added after their app write packets are captured and verified.

## Installation for testing

Copy `custom_components/ultimea` to your Home Assistant config:

```text
/config/custom_components/ultimea
```

Restart Home Assistant, ensure the D80 Boom is powered/advertising, then open:

**Settings → Devices & services**

Home Assistant should discover it automatically as an ULTIMEA device. You can also choose **Add Integration → ULTIMEA** and select/enter the BLE address.

## Bluetooth behavior

The integration never starts/stops the system Bluetooth scanner. It uses Home Assistant's Bluetooth manager to obtain the best connectable route, including supported ESPHome Bluetooth proxies.

By default the integration keeps the BLE connection open so changes generated by the D80 can arrive immediately. In integration options you can disable **Keep Bluetooth connection open**; commands then connect on demand and release the soundbar after the configured delay so the official phone app can connect.

## Volume maximum

The D80 protocol uses an integer absolute volume. Home Assistant needs a normalized 0.0–1.0 value, so the integration defaults to a maximum of 100. If your D80 firmware uses another maximum, change **Maximum D80 volume** in integration options.

## Protocol notes

Verified common channel:

```text
Write:  27758d11-bf3a-4ac6-bee5-6259ccb7c9b7
Notify: 27758d22-bf3a-4ac6-bee5-6259ccb7c9b7
```

Commands begin with `AA`, responses with `BB`. The checksum is the low byte of:

```text
0xAA + reserved + group + command + sum(data)
```

The integration validates response frames before applying state.

## Status

Initial reverse-engineered/test build. The protocol commands included here were validated against a Poseidon D80 Boom and implemented generically for the model, not for one MAC address.


## v0.1.2

- Use the Bluetooth address as the config-entry discovery unique ID while keeping the D80 serial in device metadata/identifiers.
